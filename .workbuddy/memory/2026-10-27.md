## aihot 榜单停摆一个月的根因（已修）

- 症状：`leaderboard_data.json` 的 aihot 快照停在 2026-09-24，aihubmix 正常到 10-26。
- 根因：**页面改版，`lb-*` class 全被移除**。旧正则靠 `lb-model-entry` / `lb-rank-number` /
  `lb-score-cell` / `lb-evidence-cell` 匹配，实测在新页面上出现次数全是 0 → 解析 0 条；

  已重写 `extract_entries`，现在稳定解析 30 条。

  跨改版对比会一次性炸出 24 条假 diff。要么接受一次噪音，要么把首次新快照当「口径基线」直接写入不对比。
